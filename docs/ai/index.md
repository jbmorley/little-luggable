# Generation

No AI was used in the creation of the Little Luggable hardware designs, and all photographs, images, and text used in the project, and on this website are human-authored.

Some AI tooling was used to generate support scripts for this website. This code has been reviewed thoroughly and its use is limited in scope. Source code created using AI is clearly marked and no copyright or license is asserted for these files.

## docs/assets/js/

- [`model-home.js`](https://github.com/jbmorley/little-luggable/blob/main/docs/assets/js/model-home.js)---JavaScript to animate the 3D model transition back to its home position

## scripts/

- [`blender-materials.py`](https://github.com/jbmorley/little-luggable/blob/main/scripts/blender-materials.py)---Python script to create Blender materials
- [`optimize-model.sh`](https://github.com/jbmorley/little-luggable/blob/main/scripts/optimize-model.sh)---Bash script calling `gltf-transform` to simplify GLB models
- [`recolor-nabla.py`](https://github.com/jbmorley/little-luggable/blob/main/scripts/recolor-nabla.py)---Python script to apply a color palettes to WOFF SVG fonts
- [`resize-images.sh`](https://github.com/jbmorley/little-luggable/blob/main/scripts/resize-images.sh)---Bash script to generate multiple sizes for images hosted on this website

# Tools

Little Luggable was created using [Autodesk Fusion](https://www.autodesk.com/trust/trusted-ai/ai-transparency-cards), on operating systems (macOS and Linux) known to be developed in part using AI. [Claude](https://claude.com) was used for research and as a search proxy.
