## Shortcuts

### Bluetooth

The keyboard can be paired with multiple devices.

- **Lower + Esc 1, 2, 3, 4** – select Bluetooth device
- **Lower + F5** – clear the current Bluetooth pairing

### Symbols

The keyboard is designed to be as close to a regular staggered key layout as possible. Since it's narrower than a standard keyboard, symbols typically to the right of the keyboard share space with the right-side letters and are accessible using the **Raise** modifier.

### Emoji

Dedicated emoji keys (achieved by unicode modifier key sequence macros) are available under many letters using the **Lower** modifier. This is experimental and the mapping is likely to evolve over time (I'd like to find room for  🥹, 🤯, and 👍 at the very least).

- **QUERTY**
  - **Lower + Q** – 🤔
  - **Lower + W** – 🧐
  - **Lower + E** – 😬
  - **Lower + R** – 🥲
  - **Lower + T** – 🙃
  - **Lower + Y** – 🫠
  - **Lower + U** – 😭
  - **Lower + I** – 🥰
  - **Lower + O** – 😘
  - **Lower + P** – 🤗
- **ASDF**
  - **Lower + A** – 🤞
  - **Lower + S** – 👆
  - **Lower + D** – 👌
- **ZXCV**
  - **Lower + Z** – ❤️
  - **Lower + X** – 🎉
  - **Lower + C** – 👀

### Firmware Version

You can trigger a macro to type in the current firmware version and build number using **Lower + Raise + A**.
